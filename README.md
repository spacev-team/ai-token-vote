# AI 토큰 투표 · AI 부트캠프 1기 합동 공유회

> 당신의 토큰을 가장 마음에 든 발표자에게 주세요.

익명 인기투표를 "가장 마음에 든 발표자에게 AI 토큰을 보낸다"는 세계관으로 만든 웹페이지입니다.
실습반(8/19)과 이론반(8/20)은 **같은 디자인, 다른 주소**를 씁니다.

## 바로 열어보기

```
open vote.html      # 투표자용 메인 (반 선택)
open admin.html     # 관리자용 대시보드
```

| 화면 | 주소 | 누가 보나 |
| --- | --- | --- |
| 메인 (반 선택) | `index.html` 또는 `vote.html` | 참석자 — QR/슬랙으로 이것만 공유 |
| 실습반 투표 | `vote.html?class=practice` | 참석자 (반을 정해서 공유할 때) |
| 이론반 투표 | `vote.html?class=theory` | 참석자 (반을 정해서 공유할 때) |
| **관리자 대시보드** | `admin.html` | 진행자만 — 여기서 결과 링크로 이동 |
| 실습반 결과 | `result.html?class=practice` | 진행자만, 행사날 큰 화면 |
| 이론반 결과 | `result.html?class=theory` | 진행자만, 행사날 큰 화면 |

투표자 화면 어디에도 결과로 가는 링크가 없습니다. 결과는 `admin.html` 을 아는 진행자만 열 수 있어요.

투표 페이지와 결과 페이지는 파일이 완전히 분리되어 있어서, 투표하는 사람이 실수로 중간 집계를 볼 일이 없습니다.

## 파일 구조

```
투표/
├── index.html            루트 접속 시 vote.html 로 이동만 시킴
├── vote.html             투표자용: 반 선택 → 투표 (1·2·3단계)
├── admin.html            진행자용 대시보드 (결과 링크는 여기에만)
├── result.html           결과 화면 (4·5·6단계)
├── assets/
│   ├── config.js         ★ 발표자 명단 · 행사 설정 · 백엔드 주소
│   ├── store.js          투표 저장소 (데모 / 실제 집계 전환)
│   ├── characters.js     로봇 · 토큰 · 왕관 SVG
│   ├── style.css         디자인 시스템과 모든 애니메이션
│   ├── vote.js           투표 화면 로직
│   └── result.js         결과 화면 로직
└── apps-script/
    └── Code.gs           실제 집계용 백엔드 (선택)
```

**고칠 파일은 `assets/config.js` 하나입니다.** 발표 제목은 아직 비어 있으니 채워주세요.
비워두면 카드에 "발표 주제 준비 중"으로 표시됩니다.

## 화면 흐름

**투표자**

1. `당신의 토큰을 가장 마음에 든 발표자에게 주세요.` + 발표자 카드 목록
2. 카드를 누르면 확인 시트 → `○○님에게 토큰을 보낼까요?`
3. 토큰이 위에서 떨어져 로봇 입으로 들어가고, 로봇이 냠 하고 먹습니다 (약 1.9초)
4. `토큰 전달 완료!` — 로봇이 배부른 표정으로 바뀝니다

득표수와 순위는 투표자에게 **어느 단계에서도** 보이지 않습니다.

**결과 공개**

1. `모두의 토큰이 전달됐어요.` + 로봇들과 떠다니는 토큰
2. `결과 보기` → 토큰들이 중앙으로 모이고 `토큰을 세고 있어요…` (약 2.5초)
3. 화면이 어두워졌다 밝아지며 우승자 공개, 왕관이 떨어져 씌워지고 컨페티

## 옵션

| 하고 싶은 것 | 방법 |
| --- | --- |
| 득표수 숨기기 | `config.js` 의 `showTokenCount: false`, 또는 주소에 `&count=0` |
| 전체 집계표 보기 (기록용) | 주소에 `&detail=1` |
| 테스트 후 내 투표 기록 지우기 | 주소에 `&reset=1` — **행사 당일 이 주소는 공유하지 마세요** |

동점자가 나오면 자동으로 공동 1위로 표시되고, 왕관도 각자 씌워집니다.

## 실제 집계 모드로 바꾸기

> 지금 기본값은 **데모 모드**입니다. 투표가 접속한 기기의 브라우저에만 저장되므로
> **여러 사람의 표가 합산되지 않습니다.** 화면 확인용입니다.
> 행사에 쓰려면 아래를 반드시 해주세요.

1. Google 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. `apps-script/Code.gs` 내용을 전부 붙여넣고 저장합니다.
4. **배포 → 새 배포 → 웹 앱** 으로 배포합니다.
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
5. 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을
   `assets/config.js` 의 `REMOTE_ENDPOINT` 에 붙여넣습니다.

```js
const REMOTE_ENDPOINT = 'https://script.google.com/macros/s/AKfy...../exec';
```

6. 이 폴더를 참석자가 접속할 수 있는 곳에 올립니다.
   (사내 정적 호스팅, GitHub Pages, Netlify 드래그앤드롭 등 아무거나 됩니다.
   파일을 그냥 열어서는 다른 사람이 접속할 수 없습니다.)

### 익명성과 중복 투표

- 스프레드시트에는 **시각 · eventId · presenterId · 무작위 투표자 토큰**만 남습니다.
  이름·이메일·IP는 저장하지 않으므로 누가 누구를 뽑았는지 알 수 없습니다.
- 중복 투표는 브라우저에 저장된 무작위 토큰으로 막습니다.
  사내 행사 규모에서는 충분하지만, **작정하고 브라우저를 바꾸면 한 번 더 넣을 수 있습니다.**
  로그인 기반으로 완전히 막고 싶으면 알려주세요 — Apps Script 를 도메인 제한 방식으로 바꾸면 됩니다.

## 브라우저

최신 Chrome / Safari / Edge, iOS·Android 모바일 브라우저에서 동작합니다.
기기 설정에서 "동작 줄이기"를 켠 사용자에게는 애니메이션이 자동으로 생략됩니다.
